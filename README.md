# Sail-Racing

A cross-platform sail racing app built with [.NET MAUI](https://learn.microsoft.com/dotnet/maui/), targeting Windows, iOS, and Android from a single C# codebase.

## Getting started

Requires the .NET SDK with the MAUI workload installed:

```bash
dotnet workload install maui
```

Build and run:

```bash
dotnet build
dotnet build -t:Run -f net9.0-windows10.0.19041.0
```
